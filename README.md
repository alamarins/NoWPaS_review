This repository contains the data and code used in the review manuscript "Salmonid science on the move: twenty years of research through the lens of early career researchers".

- NoWPaS_talk_characterisation.xslx: the database where abstracts information have been collected.
- NoWPaS_analysis.R: the R script used for analysis and figures. Reads the database as input data. Exports figures and models results into the following folders.
- figures: folder containing the exported figures in png.
- results_models: folder containing the exported models results in csv.
- NoWPaS_network_interactive_light.html: the interactive co-occurence network of the NoWPaS abstracts.
